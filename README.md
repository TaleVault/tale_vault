## 📖 About TaleVault

For years, big corporations have shown us how poorly they treat their users. From ignoring basic privacy rights and locking features behind paywalls, to silently using **our creative work to train their AI models** - it needs to STOP.

TaleVault was born to be the exact opposite. Built from the ground up to give creators a real choice: zero-knowledge privacy and true ownership over features paid for with your personal data.

### 🛡️ Core Values
* **Your work stays truly yours:** Uncompromising focus on author rights and easy data exports. No lock-in.
* **Zero-Knowledge Architecture:** End-to-end encryption ensures your private data is safe and inaccessible to server admins or bad actors.
* **100% FOSS:** Completely free and open-source. No subscriptions, paywalls, or hidden fees.
* **Anti-Corporate & Anti-AI Scraping:** We actively implement measures so your creative stories never feed AI models.

---

## 🛠️ Tech Stack

* **Client:** SvelteKit (Svelte 5), Tailwind CSS, Paraglide JS
* **Server:** Supabase (PostgreSQL, Auth, RLS)
* **Security:** Web Crypto API (AES-GCM, RSA/ECC)
